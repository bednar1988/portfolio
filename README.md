# Portfolio Dashboard

Investment portfolio dashboard.

## Structure

```
portfolio/
├── backend/
│   ├── Dockerfile
│   ├── main.py
│   └── requirements.txt
├── frontend/
│   └── index.html
└── data/
```

## Docker build


# Build and push
docker build -t bednar1988/portfolio:0.1.1
docker push bednare1988/portfolio:0.1.1

## Frontend update

Edit `frontend/index.html` and replace in dest frontend folder.
